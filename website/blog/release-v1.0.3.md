# Rilis lapeeh v1.0.3: Rilis Pemeliharaan

Ditulis pada **1 Januari 2026** oleh **Tim lapeeh**

Kami dengan bangga mengumumkan rilis **lapeeh v1.0.3**. Update ini fokus pada pemeliharaan rutin, peningkatan stabilitas, dan pembaruan dependensi untuk memastikan framework tetap handal.

## Apa yang Baru? 🚀

- **Peningkatan Stabilitas**: Perbaikan kecil pada sistem internal CLI.
- **Pembaruan Dependensi**: Memperbarui paket-paket pendukung ke versi terbaru.
- **Perbaikan Bug**: Menangani beberapa masalah kecil yang dilaporkan.

## Cara Upgrade

Bagi pengguna baru, cukup jalankan:

```bash
npx lapeeh init my-project
```

Bagi pengguna lama yang ingin update ke versi terbaru:

```bash
npm install lapeeh@latest
```
