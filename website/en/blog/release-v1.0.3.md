# Release lapeeh v1.0.3: Maintenance Release

Written on **January 1, 2026** by **lapeeh Team**

We are proud to announce the release of **lapeeh v1.0.3**. This update focuses on routine maintenance, stability improvements, and dependency updates to ensure the framework remains reliable.

## What's New? 🚀

*   **Stability Improvements**: Minor fixes to the CLI internal system.
*   **Dependency Updates**: Updated supporting packages to their latest versions.
*   **Bug Fixes**: Addressed several small issues reported.

## How to Upgrade

For new users, simply run:

```bash
npx lapeeh init my-project
```

For existing users who want to update to the latest version:

```bash
npm install lapeeh@latest
```

Thank you for being part of the lapeeh Framework journey!
